# Research and development roadmap

These are planned tasks; a checklist item is not complete merely because this document exists.

- [x] Publish initial taxonomy in Markdown, JSON and OPML.
- [x] Include editable mind maps and source rules.
- [x] Provide structural integrity validation.
- [x] Establish the dedicated GitHub repository.
- [ ] Agree review and merge conventions for major revisions.

## Phase 1 — GA-by-GA coverage audit

- [ ] Build a master bibliography of GA volumes, books and dated lectures.
- [ ] Compare every GA work with the 26 domains; identify gaps and missing branches.
- [ ] Verify volume, chapter and lecture URLs.
- [ ] Track edition, translation, authorship and transcription status.
- [ ] Expand and revise the hierarchy only where original texts justify it.

## Phase 2 — Foundational research

- [ ] Domains 01–04: thinking, Goethean science, initiation and worldviews.

- [ ] Domains 09–12: constitution of man, consciousness, biography, evolution.
- [ ] Domains 13–16: Christology, mystery traditions, civilizations and spiritual opposition.

## Phase 3 — Applied and artistic disciplines

- [ ] Domains 17–21: natural sciences, medicine, education, agriculture and social economy.
- [ ] Domains 22–26: art, Goetheanum, eurythmy, festivals and anthroposophical organization.

## Phase 4 — Passage-level knowledge graph

- [ ] Store per-concept source evidence with exact book section or dated lecture.
- [ ] Add original German terms, translations, aliases and chronology.
- [ ] Add typed, source-supported crosslinks; resolve duplicate canonical ideas.
- [ ] Mark every entry as lead / located / verified / contested.

## Phase 5 — HTML Atlas

- [x] First-pass region → domain → subdomain → concept browser (static prototype; not deployed).
- [ ] Source-linked concept pages with concise quotations and faithful paraphrase.
- [x] First-pass search, concept routes, related concepts, source gateway and 14 archive-topic bridges.
- [ ] Source coverage dashboard, richer concept comparisons, chronology and graph views.
- [x] Responsive CSS and offline internal JSON and JS validation.
- [ ] Real-browser accessibility and navigation testing; external link reviews and deployment.

## Quality gates

Do not silently remove stable IDs. Do not label passages verified without direct checking. Prioritize source fidelity over rapidly increasing node counts.
