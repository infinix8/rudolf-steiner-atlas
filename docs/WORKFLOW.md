# GitHub working method

The repository is the canonical home for the evolving **source-grounded Rudolf Steiner Atlas**.

1. Record coherent audits, classification changes, or interface work as GitHub issues.
2. Prefer a focused branch and pull request for major research changes.
3. Preserve node IDs. Record aliases and moved-parent relationships.
4. Support teaching claims with an exact authored chapter or dated lecture where possible; GA volume references alone are leads.
5. Run `python tools/validate_taxonomy.py` and inspect the diff.
6. Record what changed, evidence status, unresolved uncertainties and any changes to crosslinks.
7. Merge after review; update CHANGELOG for meaningful revisions.

ChatGPT can commit or propose further changes in future sessions when repository access is available. No unattended or automatic background updates are implied.
